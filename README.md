An original 20-life card duel for [make.fun's best card game](https://make.fun/c/best-card-game-20261122-1826): four suits, same-suit Surge combos, and an Ashen Warden who telegraphs every plan.

Play it: serve `game/` and open `index.html`, or run `node serve.ts` and visit http://localhost:8080.

Screenshots: `?shot=title|table|win|loss&seed=1` stages each screen deterministically.
